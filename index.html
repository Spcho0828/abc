현재 표의 필터 결과 전체 점검

금액·시간·반복·취소·집 주변·장거리 결제를 한 번에 점검합니다. 기준 해당은 추가 확인 후보입니다. 회사 규정과 업무 목적을 확인한 후 해석하세요.

점검 기준 설정

업무시간은 08:00~19:59, 주말은 토·일로 가정합니다. 심야는 22:00~05:59, 분할 후보는 60분 내 결제로 봅니다. 날짜·시간은 내역의 한국 현지 시각 기준입니다.

위치 분석 없이도 금액·시간 시나리오를 점검할 수 있습니다. 위치 시나리오는 위치 분석이 필요합니다. 필터나 기준 변경 후 다시 실행하세요.

Gemini 추가 분석

현재 표의 필터 결과 전체 분석

위치 분석 후 20개 시나리오 점검 결과를 함께 Gemini에 보내 종합 보고서를 만듭니다.

Gemini API 키 발급 ↗

Google Gemini로 날짜·시간·금액·업종·직선거리·판정·시나리오 점검 결과와 추가 질문을 전송합니다. 사용자 이름, 집·가맹점 주소, 카드번호, 승인번호, 좌표는 제외합니다. API 키는 이 탭에서만 유지되며 저장하지 않습니다. 사용량에 따라 Google API 비용이 발생할 수 있습니다.

Gemini 분석 보고서

이 사이트 서버에는 파일·집 주소·API 키를 저장하지 않습니다. 주소 확인 시 집·가맹점 주소를 카카오로 전송합니다. 새로고침하면 분석 내역이 사라집니다.

카카오 지도 연결

카카오디벨로퍼스에서 앱을 만들고 카카오맵 사용 설정을 ON으로 바꿔주세요.

REST API 키 대신 JavaScript 키를 사용하세요. 키는 현재 탭에서만 유지됩니다.

앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 위 주소를 등록하세요.
